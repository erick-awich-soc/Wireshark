# Wireshark Labs

**PLEASE NOTE : OPEN FILE COMMIT DETAILS IN ORDER TO SEE A DETAILED DESCRIPTION OF EACH SCREENSHOT**

## Overview
This repository documents my practical learning and hands-on labs using Wireshark, an open-source network protocol analyzer used to capture, inspect, and troubleshoot network traffic.

## Objectives
- Understand network protocols and packet structures.
- Capture and analyze network traffic.
- Use display filters to isolate specific packets.
- Analyze TCP, UDP, DNS, HTTP, ICMP, and ARP traffic.
- Identify network issues and suspicious communication.
- Develop practical network troubleshooting and SOC analysis skills.

## Tools Used
- **Wireshark** — Network protocol analysis.
- **Linux** — Lab environment and networking commands.
- **Sample PCAP files** — Packet capture analysis.
- **Windows server** - Capture Traffic to and From the server
- **Pfsense** - capture traffic that cross the firewall
- **Wazuh** - EDR/XDR related traffic

## Labs and Projects

| Lab                     | Description                                                   |
| ----------------------- | ------------------------------------------------------------- |
| Packet Capture          | Capture and inspect live network traffic.                     |
| Protocol Analysis       | Examine TCP, UDP, DNS, ICMP, and ARP packets.                 |
| Display Filters         | Filter traffic by protocol, IP address, and port.             |
| TCP Analysis            | Investigate TCP handshakes, retransmissions, and connections. |
| DNS Analysis            | Examine DNS queries and responses.                            |
| Network Troubleshooting | Identify packet loss, connection issues, and unusual traffic. |
| Security Analysis       | Investigate suspicious traffic patterns using PCAP files.     |


## Skills Developed

- Packet analysis
- Network protocol analysis
- TCP/IP troubleshooting
- Network traffic investigation
- Basic network security monitoring
- SOC investigation fundamentals

## Disclaimer

All experiments are conducted in authorized lab environments or using publicly available sample captures. Sensitive information is excluded from published captures.
